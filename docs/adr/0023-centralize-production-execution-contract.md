# 生成共用一份任务实现

面板、CLI、MCP 和工作区调用同一生成任务函数，统一输入校验、费用范围、提交、查询和结果保存。确定性请求不强制经过内部 Operator、Crew Intent 或另一套计划编译；CLI/MCP 只做协议转换。

任务保存固定输入、目标与幂等身份，提交不明先查询，晚到结果作为候选保留。原生效果按固定版本本地渲染，不在帧回调生成。现有复杂 Workflow 按真实依赖继续运行，不为单步效果复制其分层。

本条已按新方向收敛，替代原文的“禁止 MCP”和所有任务强制 ProductionSpec/Mandate 对象要求。必要费用授权与凭据隔离继续保留；细节见[主设计](../design/flovart-native-effects.md)。
