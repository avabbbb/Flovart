# 原生效果采用一条生成路径与独立本地渲染

用户确认插件为主要入口、先 AE/PR 再 PS、生成素材与场景替换、缓存完成后调原生参数，以及 Agent 双入口。生成任务使用同一业务实现和持久素材；宿主原生效果直接读取固定版本渲染，不能依赖 Agent、浏览器或远程生成在线。

CLI 与 MCP 是同一能力的协议入口，确定性调用不再强制经过内部 Operator/制作组。选择这种短路径，接受各宿主有少量直接适配代码，换取更少状态、副本和错误来源；不提前建立跨宿主通用插件内核。

本决定替代旧“禁止公开 MCP、只允许外部主对话、固定导演/Operator 层级”的目标。当前 Browser 工具仍保持现有显式绑定，插件独立生成与替换范围两项尚未返回 ASK 选择，按[主设计](../design/flovart-native-effects.md)中的推荐假设处理；这不是代码重构已完成的声明。
