# 沉浸式翻译对标 → Flovart 插件上架方案

调研日期：2026-11-06。来源：immersivetranslate.com 定价页与会员协议（经 masonailab.com 2026-08-13 核查的整理）、官方 FAQ 与快速开始文档。价格以官方账号页为准。

## 1. 产品模式

- 核心价值单一清晰：保留原文、双语对照。从网页扩展到 PDF、EPUB、图片、视频字幕、在线会议字幕、输入框翻译。
- 多端：Chrome / Edge / Firefox / Safari 扩展 + 桌面客户端 + Android / iOS。扩展是主入口，其他端共用账号。
- 可自带 API key（OpenAI / Claude / DeepL 等），费用由模型供应商结算；也可用官方托管模型（付费额度）。

## 2. 插件 UI

- 工具栏图标（引导用户固定）→ 弹出面板：一键翻译、目标语言、翻译服务、「更多」进入文档翻译。
- 页面右侧悬浮快捷按钮；右键菜单「翻译网页/显示原文」；快捷键 Alt+A（macOS Option+A）。
- 按站点排除规则、只翻译主要内容、显示样式等设置放在面板二级。高频操作一层，其余渐进披露。

## 3. 商业模式

| 方案 | 价格 | 额度 |
| --- | --- | --- |
| Free | 免费 | 每日请求 fair-use 限制，注册后额度更高 |
| Pro | US$14.99/月，US$124.99/年 | 每月 2,000 万 advanced tokens |
| Max | US$34.99/月，US$289.99/年 | 5,000 万 advanced + 200 万 premium tokens |

- 试用到期自动续订；月订首购 24 小时、年订 72 小时内可退款（未大量使用）。
- 每账号最多 8 台设备同时使用（按浏览器计）。
- 辅助：家庭套餐（共享 Pro）、礼品卡、独立高级功能（漫画翻译、PDF Pro、BabelDOC 每月免费 token）。
- 要点：免费版真可用（拉新），付费卖的是「托管模型额度 + 高级功能」，而不是锁基础功能。

## 4. 注册与登录

- 不登录即可使用基础翻译；登录后提高免费额度、设置与订阅跨端同步。
- 微信登录仅支持电脑端（官方 FAQ）。其他登录方式（邮箱 / Google 等）【待核实】。
- 订阅管理在个人中心 Billing；App Store 等渠道购买需在对应平台取消。

## 5. 映射到 Flovart

### 内测阶段（0.3.x）

- 保持免登录 + BYOK：已有 keyVault v2 本地加密存储用户自己的 key，对应沉浸式翻译「自带 API key」路径。登录/注册维持占位。
- 浏览器插件（feat/plugin-context 方向）做一件事：把当前网页的图片 / 视频 / 文字一键送进 Flovart 画布（对应「一键翻译」的单一价值）。
- 入口照搬：工具栏面板（发送到画布、打开 Flovart）、右键菜单「发送到 Flovart」、快捷键；悬浮按钮默认关闭，避免干扰。
- 所有入口链接线上站 flovart.avabbbb.com。

### 商业化阶段（待定）

- Free：BYOK 全功能 + 本地存储，不限量。
- Pro：托管模型额度（图像/视频生成积分）、云端同步工程、多设备。先试用再订阅，明示自动续订与退款窗口。
- 可选：团队/家庭共享、礼品卡。
- 前置工作：账号体系（先邮箱 + 微信扫码，桌面优先）、支付渠道、用量计量、服务协议与隐私政策。

### 上架清单

1. Chrome Web Store（开发者账号一次性 US$5）、Edge Add-ons、Firefox AMO；Safari 放后。
2. 权限最小化：activeTab + contextMenus + storage，避免 all_urls，审核更快。
3. 隐私政策页（说明数据只在本地、key 不上传）、商店截图、小于 30 秒演示视频。
4. 内测用「未公开」发布，反馈稳定后转公开。
