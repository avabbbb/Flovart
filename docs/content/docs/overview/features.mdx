Flovart 当前是本地优先的 Workflow 与 Agent 创作工具。正在开发的新方向是原生效果插件：先在 AE/PR 生成素材与替换场景，再本地调节效果，复杂编排时展开 Flovart。该方向仍是设计/开发中，不能作为已可用功能。

## 当前工作区

| 工作区 | 职责 | 当前边界 |
| --- | --- | --- |
| Workflow | 提示词、参考素材、模型、生成依赖、任务与结果 | 已有主体；具体能力按真实 Provider 与项目验证 |
| Table | 独立节点式媒体处理 | 入口已有，主体仍待实现 |
| Agent | 助手接入、任务、上下文与产物协作 | 已有接入 UI；双向深度会话按助手逐个实现/验证 |

Workflow 可组织图片、文本、视频、音频及配置节点，使用 PromptBar、连线、本地素材和生成结果继续编辑。节点选择、媒体拖入、引用、操作候选与恢复的待验证变更见[待测试确认](../progress/pending-test.mdx)。

三个工作区保持自己的状态与历史。Table 不与 Workflow 混图，Agent 不作为第四张生成画布。已删除 Canvas/Art 不恢复。

## CLI、Skill 与助手

现有 Operation Skill 通过 CLI 让助手检查和操作可见 Workflow；日常使用 status、workflow.inspect、workflow.selection.get、workflow.apply、workflow.node.run，ensure 负责准备连接。command.list/schema 属于 discovery、兼容诊断或调试。

Codex、Claude、OpenCode、DSH、WorkBuddy 与 TeleAgent 的接入程度不同，不能用一个工具调用成功声称全部可用。当前已提供只投影五个稳定操作的本地 stdio MCP；真实 TeleAgent 客户端导入与 Agent tracer 仍为 External Gate。详细使用见[Skill 手册](../../../overview/skill-guide.md)、[生态架构](../../../design/ecosystem/TARGET_ARCHITECTURE.md)和[支持矩阵](../../../../SUPPORT_MATRIX.md)。

## 创作软件插件

当前 PS/PR/AE/Resolve 有 Experimental 面板包与素材桥接代码，仍待真实宿主导入、处理、回写验证。原生效果、关键帧、保存重开与离线导出是待开发/验证能力，包构建不代表这些能力已实现。

完整产品、交互、实现、Benchmark 与宣传边界统一见[主设计](../../../design/flovart-native-effects.md)，不在功能页复制目标规格。

## 本地数据与模型

- 当前项目、素材与生成记录主要保存在浏览器本地，不承诺云同步。
- 当前浏览器路径使用本地 key 并前端直连；Desktop Runtime 有独立凭据/任务实现，不能声称所有入口已统一托管。
- 用户自行配置模型服务；连接器、Skill、项目与日志不应接收原始 Provider key。
- 真实模型质量、费用、取消及宿主兼容性需分别验证。

未完成工作见[后续待办](../progress/todo.mdx)。正式能力仅在真实验证后更新。
