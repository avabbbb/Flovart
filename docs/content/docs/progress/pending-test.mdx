## 本轮：本地文件夹直读素材

按“素材就地读取、默认引用原文件”的方向把本地素材从“导入副本”扩出第二条路径；原导入路径不变，仍服务文件粘贴与外部来源。

- 新增 `services/localFolderSource.ts`：目录授权（`showDirectoryPicker`）、目录句柄本地持久化、按深度/数量上限扫描媒体条目、按相对路径读取原文件、缩略图缓存、权限查询与重新授权。决策见 [ADR 0071](../../../adr/0071-local-folder-reference-media.md)。
- 节点用 `local-folder:<folderId>/<相对路径>` 引用素材，`sourceType` 为 `localFolder`；项目 JSON 不保存字节、base64 或临时 URL。`loadFallbackMediaBlob` 增加该前缀解析，`useWorkflowMediaUrl` 原样透出“权限失效 / 原文件被移动”的原因，便于用户重新定位。
- 新增 `components/workflow/LocalFolderBrowser.tsx` 并挂到 Workflow 侧栏新增的「本地文件夹」页签（真实入口，非占位）：可“选择文件夹”或拖入文件夹、按类型与文件名筛选、缩略图进入视口才生成并缓存、多选后一次性“放入画布”。未选中的条目不会生成节点。
- 批量放入画布共用一个 Draft ChangeSet；插入前只读取选中文件的尺寸与时长，不复制字节。
- 视频封面复用画布既有的按需封面补齐路径，对文件夹引用的视频同样生效。
- 本轮证据：`npx tsc --noEmit` 通过；新增 `tests/localFolderSource.test.ts`（11 项）与 `tests/localFolderBrowser.test.tsx`（6 项）通过；`npm run docs:check` 通过。
- 待用户实测：真实 Chrome/Edge 中授权一个含子目录与中文路径的文件夹，确认缩略图与“放入画布”可用、刷新后“重新连接”能恢复、移动或重命名原文件后提示重新定位。宿主 iframe 中目录授权可能被浏览器禁用，未在本轮验证。
- 未做：助手直接给文件夹路径的读取（需本地服务新增受限目录接口）；导出/打包对引用失效的检测；轻面板的「任务 / 打开画布」入口收敛。
