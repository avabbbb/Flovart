## Agent surface 与 Assistant drawer

当前代码已经形成：
- 顶栏 Canvas | Table | Agent 三个 surface；
- Agent 页只展示本地/外部 Coding Agent 连接与状态；
- Canvas/Table 右侧 drawer 为 Assistant / Context / History；
- Agent 页打开时不显示 Assistant drawer。

仍需确认：
- 真实用户从 Canvas/Table → Agent → 返回的心智与项目状态是否自然；
- 窄窗口、项目为空、断线、重连时不会出现重复 Host picker 或双聊天；
- Codex / WorkBuddy 的“已准备”状态与真实登录/会话状态不会被用户误解。

## workflow.project.use 回归

当前已知问题：`workflow.project.use` 可以返回成功，但 browser → agent 的 active project snapshot 可能尚未完成回环，随后 inspect/lease 仍读旧项目。

通过标准：
1. 切换到既有项目 X；
2. 等到 Browser authority 明确 ack X；
3. 下一次 inspect / mutation 都绑定 X；
4. 不出现 `LEASE_TARGET_CHANGED` 的假冲突；
5. 超时时显式失败，不回显假成功。
